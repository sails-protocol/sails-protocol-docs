Every action on a Sails node — publishing offers, opening trades, managing escrow — belongs to a participant identified by an **Ed25519 public key**. You generate the keypair on your own device, register the public key with proof that you hold it, and prove control again at each login by signing a challenge. See [Authentication](/api/authentication) for the step-by-step flow.

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| POST | `/v1/identity/register-challenge` | — | Issue a one-time registration challenge |
| POST | `/v1/identity/participants` | — | Register a participant (proof of possession required) |
| GET | `/v1/identity/participants/:id` | — | Public profile of any participant |
| POST | `/v1/identity/challenge` | — | Issue a login challenge |
| POST | `/v1/identity/authenticate` | — | Verify a signed challenge and get a session token |
| GET | `/v1/identity/me` | Session | Your own full participant record |
| POST | `/v1/identity/ws-ticket` | Session | Single-use ticket for WebSocket connections |

Registration, challenge, and authentication endpoints are rate-limited.

---

## Issue a registration challenge

**`POST /v1/identity/register-challenge`**

<ParamField body="publicKey" type="string" required>
  Your Ed25519 public key, hex-encoded (64 characters).
</ParamField>

<ResponseField name="challenge" type="string">
  One-time challenge (64 hex characters) to include in your proof-of-possession signature.
</ResponseField>

<ResponseField name="expiresIn" type="integer">
  Seconds until the challenge expires (120 by default).
</ResponseField>

---

## Register a participant

**`POST /v1/identity/participants`**

Sign this UTF-8 message with the private key, then submit it with the public key:

```text
sails-registration-proof-of-possession:v1:<challenge>:<displayName or empty>
```

<ParamField body="publicKey" type="string" required>
  Your Ed25519 public key, hex-encoded (64 characters). Never send the private key.
</ParamField>

<ParamField body="signature" type="string" required>
  Hex-encoded Ed25519 signature of the message above.
</ParamField>

<ParamField body="displayName" type="string">
  Optional display name. It's part of the signed message, so it must match exactly what you signed.
</ParamField>

Returns `201` with your participant record (including its `id`).

<CodeGroup>
```bash Request
curl -X POST http://localhost:3000/v1/identity/participants \
  -H "Content-Type: application/json" \
  -d '{
    "publicKey": "a3f2e1d4c5b6a7980f1e2d3c4b5a69780f1e2d3c4b5a69780f1e2d3c4b5a6978",
    "signature": "9f3c1a2b…",
    "displayName": "alice_trader"
  }'
```

```json Response (201)
{
  "success": true,
  "data": {
    "id": "5b1c2d3e-7f80-4a1b-9c2d-3e4f5a6b7c8d",
    "publicKey": "a3f2e1d4c5b6a7980f1e2d3c4b5a69780f1e2d3c4b5a69780f1e2d3c4b5a6978",
    "displayName": "alice_trader",
    "verified": false,
    "createdAt": "2026-09-21T10:00:00.000Z"
  }
}
```
</CodeGroup>

| Error | When |
| --- | --- |
| `VALIDATION_ERROR` (400) | Malformed key, missing signature, or the key is already registered |
| `AUTH_ERROR` (401) | Proof missing, invalid, expired, or already used — request a new registration challenge |

## Get a public participant profile

**`GET /v1/identity/participants/:id`**

No session required. Returns only public identity fields — use [Reputation](/api/reputation) for trust facts.

<ResponseField name="id" type="string">
  Participant ID.
</ResponseField>

<ResponseField name="publicKey" type="string">
  Registered Ed25519 public key.
</ResponseField>

<ResponseField name="displayName" type="string | null">
  Display name, if set.
</ResponseField>

<ResponseField name="peerId" type="string | null">
  Portable P2P (Pears) identity, if linked.
</ResponseField>

<ResponseField name="verified" type="boolean">
  Whether the participant is marked verified.
</ResponseField>

---

## Issue a login challenge

**`POST /v1/identity/challenge`**

<ParamField body="publicKey" type="string" required>
  Your registered Ed25519 public key, hex-encoded.
</ParamField>

Returns `{ challenge, expiresIn }`. The challenge is a 64-character hex string, valid once, for `expiresIn` seconds (120 by default).

---

## Authenticate

**`POST /v1/identity/authenticate`**

<ParamField body="publicKey" type="string" required>
  Your Ed25519 public key, hex-encoded.
</ParamField>

<ParamField body="signature" type="string" required>
  Hex-encoded Ed25519 signature of the **UTF-8 bytes of the challenge string** (not the decoded hex).
</ParamField>

<ResponseField name="participantId" type="string">
  The authenticated participant.
</ResponseField>

<ResponseField name="sessionToken" type="string">
  Opaque bearer token (64 hex characters), valid for one hour by default. Send it as `Authorization: Bearer <token>`.
</ResponseField>

Returns `401 AUTH_ERROR` if the signature doesn't verify, the challenge expired or was already used, or no participant is registered for the key.

---

## Get your own participant record

**`GET /v1/identity/me`** — session required

Returns your full participant record. Your identity always comes from the session, never from request parameters.

---

## Get a WebSocket ticket

**`POST /v1/identity/ws-ticket`** — session required

<ResponseField name="ticket" type="string">
  Single-use ticket (64 hex characters).
</ResponseField>

<ResponseField name="expiresIn" type="integer">
  Seconds until the ticket expires (30 by default).
</ResponseField>

Open the WebSocket with `?ticket=<ticket>` — see [WebSocket](/api/websocket).
